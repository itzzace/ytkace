YTKACE

An open-source YouTube enhancement for iOS. Downloads, SponsorBlock, background playback, and a player without ads.

Install

Jailbroken devices install from the repo. Everyone else sideloads the IPA.

  1. Jailbroken. Tap Add to Sileo above, or add the URL by hand in Sileo, Zebra, or Cydia. Rootless and roothide packages are both published.
  2. Sideloaded. Download the IPA from the latest release and install it with TrollStore, AltStore, SideStore, or LiveContainer.
  3. Open YouTube. YTKACE appears as its own tab and inside the native settings.
